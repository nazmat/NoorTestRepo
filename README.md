# FancyCat

## Section 1 — Command Description

FancyCat is a Node.js program that reads a text file and shows what is inside the file. It also counts how many lines are in the file.

### How to Run

Use this command in the terminal:

node fancyCat.js example.txt

The file name can be changed to another text file.

### What It Combines

FancyCat is based on the `cat` command because it displays the contents of a file. I added a line-counting feature to make the command more useful.

The program uses `process.argv` to get the file name and `fs` to read the file.
